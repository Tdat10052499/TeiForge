> Trạng thái: **đang triển khai**

## 1. Bối cảnh

| Vấn đề | Bằng chứng |
|---|---|
| Gõ `teiforge` không kèm lệnh con chỉ in trợ giúp và thoát với mã 2 | `cli.py`, `main` |
| Cấu hình model chỉ qua biến môi trường, và biến mất khi đóng cửa sổ PowerShell | Test 14/10: 6/6 lần chạy rơi vào router vì thiếu biến; test 16/10 phải đặt lại biến |

| Người dùng không thấy agent đang làm gì, ngoài vài dòng `->`/`<-` khi chạy với `--verbose` | `cli.py`, `event_printer` |

## 2. Mục tiêu

1. Cài `teiforge[tui]` xong, gõ `teiforge` là mở giao diện toàn màn hình.
2. Lần đầu mở: màn hình cài đặt tự dò Ollama, cho chọn model và thư mục làm việc, chạy thử, rồi lưu cấu hình vào `~/.teiforge/config.toml`. Từ đó không cần đặt biến môi trường nữa.
3. Màn hình chính gồm ba vùng: hội thoại, các bước agent đang làm (dựa trên chuỗi sự kiện có sẵn), và cây thư mục workspace.
4. Hỏi người dùng trước khi agent ghi tệp hoặc chạy lệnh.

Ngoài phạm vi: web UI, async/streaming từng token, docs site.

## 3. Thiết kế

### P1. Lõi (không thêm phụ thuộc)

- `teiforge/userconfig.py`: đường dẫn `TEIFORGE_HOME` hoặc `~/.teiforge`; `load_user_config()` đọc `config.toml` (dùng `AgentConfig.from_file`), `save_user_config(config)` ghi TOML đơn giản bằng thư viện chuẩn. Chỉ giao diện Textual dùng tệp này; lệnh `run`/`chat` giữ nguyên hành vi để không phá script cũ.
- `teiforge.llm.list_ollama_models(base_url)`: gọi `GET /api/tags` để liệt kê model đã tải. Lỗi mạng trả về danh sách rỗng.
- Móc xác nhận: `Agent(..., approver=fn)`; `fn(call: ToolCall) -> bool` được gọi trước mỗi lần chạy tool (cả vòng lặp LLM lẫn router). Từ chối thì tool không chạy, model nhận lỗi "The user declined...", và sự kiện `tool_result` có `declined: true`. Mặc định `approver=None` nên hành vi cũ không đổi.
- Bảo mật: không nới lỏng gì. Workspace, allow-list và `TEIFORGE_ENABLE_COMMANDS` giữ nguyên; tệp cấu hình **không bao giờ** chứa API key (key vẫn chỉ đọc từ biến môi trường).

### P2. Giao diện Textual (`teiforge/tui/`, extra `teiforge[tui]`)

- `SetupScreen`: chọn nhà cung cấp (Ollama nếu dò thấy, OpenAI, Anthropic, không dùng model), chọn model, nhập thư mục; nút "Test and save" chạy thử một câu ở luồng nền và chỉ lưu khi model trả lời.
- Màn hình chính: khung hội thoại (câu trả lời hiển thị Markdown), khung "Steps" (mỗi sự kiện một dòng có thời gian), `DirectoryTree` của workspace (tự làm mới sau khi ghi tệp), ô nhập và thanh phím tắt.
- Agent chạy trong worker thread; sự kiện được chuyển về giao diện bằng `call_from_thread`. `Esc` hủy câu đang chờ (bỏ qua kết quả), `Ctrl+Q` thoát và lưu hội thoại.
- `ApprovalScreen`: hộp thoại cho `file_writer` và `command_runner` với các nút Allow / Allow for this session / Deny; tool chỉ đọc chạy luôn.
- Lệnh trong ô nhập: `/help`, `/tools`, `/memory`, `/clear`, `/setup`, `/exit` (gõ `exit`, `quit` cũng được).
- Hội thoại lưu tự động vào `~/.teiforge/chat.json`.

### P3. CLI

- `teiforge` không kèm lệnh con, khi chạy trong terminal tương tác: mở giao diện. Nếu chưa cài `textual`: in hướng dẫn `pip install "teiforge[tui]"` cùng trợ giúp. Khi bị pipe hoặc chạy trong CI: giữ hành vi cũ (in trợ giúp, mã 2).
- Thêm lệnh tường minh `teiforge ui`.

### Phụ thuộc

- `tui = ["textual>=8.0"]`, và `textual` được thêm vào extra `dev` để CI chạy test giao diện. Lõi vẫn chỉ phụ thuộc `requests`.

## 4. Chất lượng

- Lõi: test offline như mọi khi (`ScriptedProvider`, mock `requests.get`).
- Giao diện: test bằng `App.run_test()` (pilot, không cần terminal thật), dùng `ScriptedProvider`.
- Coverage toàn bộ ≥ 85%.

## 5. Tiêu chí nghiệm thu

- [ ] Gõ `teiforge` trên Windows Terminal (máy tác giả) mở giao diện; lần đầu hiện màn hình cài đặt và tìm thấy `llama3.1`.
- [ ] Đóng và mở lại cửa sổ terminal, gõ `teiforge`: dùng được ngay, không cần đặt biến môi trường.
- [ ] Hỏi "Read meeting.txt and summarise it": khung Steps hiện `file_reader`, câu trả lời hiển thị đúng.
- [ ] Yêu cầu ghi tệp: hộp thoại xác nhận hiện ra; chọn Deny thì tệp không được tạo.
- [ ] `Esc` khi đang chờ model không làm hỏng giao diện; `Ctrl+Q` lưu hội thoại.
- [ ] `teiforge` khi bị pipe vẫn in trợ giúp như cũ.
- [ ] CI xanh trên Python 3.10–3.14, Windows và macOS.

## 6. Việc tác giả cần làm thủ công

1. Cài nhánh, chạy `teiforge` trong Windows Terminal và PowerShell, kiểm tra các tiêu chí ở mục 5.
2. Chụp ảnh màn hình hoặc GIF cho README và bài viết.
